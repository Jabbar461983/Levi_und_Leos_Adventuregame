# Levi & Leo's Adventure Game - Link's Quest

Ein episches HTML5 Canvas-basiertes Abenteuer-Spiel mit Zelda-Inspiration!

## 🎮 Spielbeschreibung

Du spielst als **Link** und musst dich durch **7 verschiedene Welten** kämpfen, um die Bösen Drachen zu besiegen. Mit jedem Level wirst du stärker, erhältst neue Waffen und kannst einzigartige Skins freischalten.

## 🌍 Die 7 Welten

1. **Wald** - Waldaxt als Boss-Waffe
2. **Wasser** - Wassertrident als Boss-Waffe
3. **Feuer** - Feuerschwert als Boss-Waffe
4. **Gift** - Giftdolch als Boss-Waffe
5. **Blitz** - Blitzstab als Boss-Waffe
6. **Gebirge** - Felshammer als Boss-Waffe
7. **Leere** - Void Klinge als Boss-Waffe

## ⚔️ Spielmechanik

### Steuerung
- **WASD** oder **Pfeiltasten** - Bewegung
- **Mausposition** - Zielausrichtung
- **Linksklick** - Angriff
- **ESC** - Spiel pausieren

### Spiel-Features
- **7 Progressive Level** - Jede Welt wird schwieriger
- **Boss-Kämpfe** - Alle 5 Level ein stärkerer Drachen-Boss
- **Blauwe Diamanten** - Sammeln und zum Freikaufen von Skins verwenden
- **6 verschiedene Link-Skins** - Mit unterschiedlichen Kosten
- **Dynamische Feinde** - Werden mit jedem Level stärker
- **Leben-System** - Passe deine HP auf

### Waffensystem
- Startest mit: **Schwert**
- Boss-Waffen: Besiege Bosse um neue Waffen freizuschalten
  - Waldaxt (Level 5)
  - Wassertrident (Level 10)
  - Feuerschwert (Level 15)
  - Giftdolch (Level 20)
  - Blitzstab (Level 25)
  - Felshammer (Level 30)
  - Void Klinge (Level 35)

### Shop-System
Kaufe im Hauptmenü-Shop einzigartige Link-Skins:
- **Classic Link** - Kostenlos
- **Red Link** - 50 💎
- **Blue Link** - 100 💎
- **Dark Link** - 150 💎
- **Gold Link** - 200 💎
- **Crystal Link** - 300 💎

Dein Fortschritt wird automatisch gespeichert (LocalStorage)!

## 🎯 Ziele
- Besiege alle 7 Welten
- Sammle möglichst viele Diamanten
- Freischalt alle Link-Skins
- Überlebe gegen immer stärkere Feinde und Bosse

## 🛠️ Technische Details

- **Entwickelt mit:** HTML5, CSS3, JavaScript (Canvas)
- **Speicherung:** Browser LocalStorage
- **Responsive:** Optimiert für Desktop und Laptop
- **Performance:** 60+ FPS auf modernen Browsern

## 🚀 Installation & Spielen

1. Lade `index.html` in deinen Browser
2. Klicke auf "Spiel Starten"
3. Verwende WASD/Pfeiltasten zur Bewegung
4. Klicke um anzugreifen
5. Sammle Diamanten und besiege alle Bosse!
